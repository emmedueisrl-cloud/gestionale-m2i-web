`ita.traineddata.gz` is the Italian OCR model from the
[tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)
repository. It is bundled locally so scanned visure can be read without a
network request. The original `ita.traineddata` was compressed with gzip;
its license is included in `LICENSE.tessdata_fast`.
